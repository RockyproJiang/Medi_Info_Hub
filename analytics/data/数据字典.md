# 多维度调研数据库 · 数据字典

> 版本 v1.0（预设数据）· 随机种子 42 · 生成器 `src/data_generator.py`
> 数据状态：**模拟调研预设数据**，真实调研到位后按同名 CSV 替换，字段口径不变。

## 通用字段

| 字段 | 类型 | 说明 |
|------|------|------|
| record_id | TEXT | 记录唯一编号（前缀 GP/BK/MD/CR/SV + 序号），可回溯原始行 |
| region_id | TEXT | 区域编码：C=城市，X=县城，R=农村（维表 dim_region） |
| sample_year | INTEGER | 调研年份（2023—2025） |
| data_source | TEXT | 数据来源标识（预设数据溯源用） |

## 4. fact_care_risk（医养融合机构风险，120 行）

15 项风险指标按 5 维组织（模型二输入，方向 + 表示值越大风险越高）：

| 维度 | 指标 |
|------|------|
| 偿债风险 | r_debt 资产负债率%(+)、r_current 流动比率(倍,−)、r_interest 利息保障倍数(−) |
| 经营风险 | r_bed 床位空置率%(+)、r_occupancy 床位利用率%(−)、r_payback 投资回收期(年,+) |
| 现金流风险 | r_receivable 医保/长护险回款周期(天,+)、r_cashflow 经营性现金流覆盖率(−)、r_advance 垫资比例%(+) |
| 政策风险 | r_policy 政策补贴依赖度%(+)、r_license 资质证照完备率%(−)、r_insurance 综合责任险投保率%(−) |
| 运营风险 | r_staff 持证护理人员比率%(−)、r_turnover 护理人员流失率%(+)、r_incident 万次服务安全事故率(+) |

> 处理后每指标追加 `r_*_norm`：已按方向统一（越大=风险越高）并标准化 0-100。

## SQL 查询示例（教学）

```sql
-- 分区域受害率
SELECT r.region_name, COUNT(*) n, ROUND(AVG(s.fraud_victim)*100,1) rate
FROM fact_survey s JOIN dim_region r USING(region_id) GROUP BY r.region_id;

-- 高风险机构清单
SELECT record_id, region_id, org_type
FROM fact_care_risk WHERE r_debt > 70 AND r_cashflow < 1;
```
